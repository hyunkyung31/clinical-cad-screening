# 공개 범위와 추가 확인

본인 실험 코드, 집계 성능, 데이터가 없는 설명과 그래프를 공개용으로 구성했습니다. 원본 Excel·환자별 행·OOF확률·실제모델·artifact reference·개인PDF는 포함하지 않았습니다. 노트북의모든출력·실행카운터·widget metadata와개인경로를정리했습니다.

UCI공식페이지의CC BY 4.0은출처표시등의조건으로공유·수정을허용하며비상업연구에만한정되지않습니다. 원본데이터재배포를의료자료라는이유만으로금지라고판정하지않았습니다. 이번에는포트폴리오에필요한코드·집계자료만선택했습니다.

남은확인은실제사용Excel과공식파일대조,공식저작자·권장인용문,본인코드의소프트웨어라이선스선택,외부라이브러리조건입니다. 데이터license가코드license를자동으로결정하지않습니다.

LR/SVM Nested는PDF기록만있고개인구현이확인되지않습니다. ANN실행환경차이,최종구성용보정OOF의선택편향,Mock추론미완료,외부검증미수행을문서에남겼습니다. 이사본에서새학습·모델재로딩·실제입력추론을수행했다고표현하지않습니다.

원본팀저장소나그Git기록을수정하지않았습니다. 공개사본의정리가기존기록노출의해결을의미하지않습니다. 재실행시환자별출력이다시생길수있으므로새산출물도별도검토해야합니다.
